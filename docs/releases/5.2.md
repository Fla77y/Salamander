## Highlights

- Release identity updated to 5.2 (build 184), retaining the compatible Salamander plug-in SDK level 103.
- New version-specific configuration under `HKCU\Software\Open Salamander\5.2`, with the previous 5.0 configuration available as an import source. The upgrade path discovers the installed plug-ins, including PictView.
- The PictView viewer now uses the Windows Imaging Component (WIC) for common Windows-supported formats, rather than unavailable proprietary PVW32 converter binaries.
- Native PictView functionality includes fit-to-window/zoom, manual multipage navigation, rotation/mirroring in memory, safe new-file WIC image export, clipboard copy/paste for supported DIB layouts and thumbnails.
- The Release x64 portable package includes the executable, compiled help, bundled application assets, PictView and its runtime resources and applicable MSVC Release runtime DLLs. A per-user Inno Setup installer is also produced.

## Native PictView controls

| Action | Shortcut |
| --- | --- |
| Fit to window | `0` |
| Zoom | `+`, `-`, mouse wheel |
| Previous/next frame | `PageUp`, `PageDown` |
| Rotate clockwise/counterclockwise | `R`, `Shift+R` |
| Mirror horizontally/vertically | `H`, `V` |
| Copy image to clipboard | `Ctrl+C` |
| Paste supported 24/32-bit DIB | `Ctrl+V` |
| Export a copy | `Ctrl+Shift+S` |
| Close viewer | `Escape` or window close |

Export supports WIC PNG, BMP, JPEG and TIFF. The output is created as a new
file: existing destination files are not overwritten. The source image remains
unchanged by in-memory transforms and export.

## Known limitations

This is **not** full feature parity with the historical proprietary PictView
engine. Timed animated GIF playback, some proprietary/legacy formats (including
RAW/CDR/PSP variants), print, screen capture, TWAIN/WIA, advanced editing/crop,
undo/history, old slideshow/navigation UI, EXIF orientation/color management
and metadata dialogs have not been migrated. GIF and multipage formats use
manual frame navigation, not timed playback.

The existing Salamander plug-in SDK still receives ANSI filename paths;
Unicode filenames that cannot be safely represented in the active code page
and arbitrary long paths are not universally supported at this boundary.
Unsupported cases must be rejected rather than silently redirected.

WIC codec availability varies with the installed Windows system and codecs.
